CuppingNotes — SCA 2025 Coffee Value Assessment (CVA)

Mendigitalkan evaluasi sensori kopi spesialti dunia. Menggantikan formulir kertas kuno dengan platform PWA enterprise yang mengkalkulasi skor deskriptif dan afektif standar SCA 2025 CVA secara real-time.

🎯 Multi-Axis Radar
Visualisasi 8 dimensi sensori (Fragrance, Acidity, Body, Sweetness, Cleanliness).
📊 Roastery Telemetry
Integrasi kurva sangrai Rate of Rise (RoR) & green bean batch inventory.
🌱 Origin Traceability
Pencatatan varietas, ketinggian tanam, dan proses pascapanen mikro-lot.
📱 Offline PWA
Dapat digunakan di lab cupping maupun roastery tanpa koneksi internet.

Keahlian inti mencakup arsitektur AI Agents & Model Context Protocol (MCP), Angular 19+, TypeScript, Python, Node.js, PHP, API REST/OpenAPI, visualisasi HTML5 Canvas/Telemetry, serta optimasi Core Web Vitals dan SEO/GEO.
